Nao Selectは、楽天の商品探索から運営者による選定、楽天ROOMへの手動登録、Pinterest投稿案の準備までを支援する、個人運営のローカルツールです。

CURRENT STATUS

開発・審査準備中

  • 運営形態運営者本人の利用
  • Pinterest API未承認・未接続
  • 現在の投稿Dry-runのみ
  • 外部トラッキングなし

Trial AccessはStandard Accessとは異なります。Trial承認だけで一般公開の自動投稿が可能になるとは扱いません。

PURPOSE

運営者の確認を中心にした商品紹介フロー

楽天市場の商品情報をそのまま自動投稿するのではなく、運営者が候補を確認・選定し、各サービスの規約と承認範囲に応じて段階的に利用する構想です。楽天アフィリエイトに関連する商品URLを扱う可能性があります。

  1. 01

    楽天商品を探索

    公式APIから取得した商品情報を期限付きキャッシュとして扱います。

  2. 02

    運営者が選定

    自動フィルターとローカル画面を使い、採用・修正・見送りを判断します。

  3. 03

    楽天ROOMへ手動登録

    ROOMへの最終投稿は運営者本人が手動で行います。ブラウザ自動操作は行いません。

  4. 04

    Pinterest投稿を準備

    タイトル、説明、alt text、ROOM URLを確認し、Pinごとの明示承認を前提にします。

  5. 05

    Analyticsを検討

    利用条件と保存設計が確認できた範囲だけを運用改善に利用する予定です。現在は未実装です。

IMPLEMENTED LOCALLY

現在確認できる実装

  • 楽天APIの読み取りと、価格・販売可否24時間／その他商品情報3か月の期限管理
  • 重複・期限切れ・不足項目を除く決定論的な候補絞り込み
  • synthetic／mockデータによる商品選定AI境界の検証
  • 運営者による採用・修正・見送りのローカル承認画面
  • 楽天ROOM用コメント準備と、手動投稿後のROOM URL登録
  • Pinterest投稿案の作成、preview、dry-run、安全ゲート
  • Pinterest API由来データを永続保存しないruntime-only設計

PLANNED AFTER REVIEW

承認・規約確認後の予定

  • Trial Sandbox検証
    Trial承認後も、作成者だけに見えるSandbox entityを使い、限定的に確認します。
  • Pinごとの投稿確認
    一括自動投稿ではなく、各Pinを運営者が選択して承認する設計を維持します。
  • Analytics
    保存・利用条件を確認し、設計が承認された後にのみ検討します。
  • Standard Access
    Trialとは別の審査段階として扱い、必要なOAuth実装とデモを準備してから申請します。

ENGLISH SUMMARY

About Nao Select

Nao Select is an owner-operated, local-first tool under development. It helps the operator discover products through the official Rakuten API, review and select candidates, prepare content for manual posting to Rakuten ROOM, and prepare Pinterest Pin drafts that may link to the resulting ROOM pages.

Pinterest API access is not currently approved or connected. The current implementation is limited to local dry-runs with synthetic data. Any future Pinterest publishing action will require the operator to knowingly approve each Pin. Trial and Standard access are treated as separate stages.
